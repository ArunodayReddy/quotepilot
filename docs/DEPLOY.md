# QuotePilot — Deploy Guide

> Goal: a public hackathon-ready URL in ~10 minutes, all on free tiers.
> Frontend → **Vercel**. Backend → **Render** (Railway works too — notes at the bottom).

## What you need

- A GitHub account with access to `ArunodayReddy/quotepilot` (done)
- A Vercel account (sign up with GitHub — 1 click)
- A Render account (sign up with GitHub — 1 click)
- Optional: Google Places API key (live agent data) and SMTP credentials (real emails)

## Step 1 — Deploy the API (Render, ~4 min)

1. Render dashboard → **New +** → **Blueprint** → connect the `quotepilot` repo.
2. Render reads `render.yaml` and creates the `quotepilot-api` web service (free tier).
3. When prompted for env vars, fill in:
   - `CORS_ORIGIN` → your Vercel URL (you'll get this in Step 2; come back and set it — or set a custom domain now if you have one)
   - `GOOGLE_PLACES_API_KEY` → your Places key (empty = labeled sample agent data; nothing breaks)
   - `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` / `EMAIL_FROM` → your mail provider (empty = emails are logged, not sent)
   - `ANALYTICS_SALT` → auto-generated by Render, leave it
4. Deploy. Note the service URL, e.g. `https://quotepilot-api.onrender.com`.
5. Smoke test: open `https://quotepilot-api.onrender.com/api/health` → `{"status":"ok"}`.
   Then `.../api/carriers?state=TX` → 11 carriers.

> Free-tier notes: the service sleeps after inactivity — first request can take
> ~30s to wake ("cold start"). The demo script accounts for this: hit `/api/health`
> once before the judges arrive. SQLite analytics live on ephemeral disk — stats
> reset on redeploy (fine for demo; Postgres is the documented upgrade path in
> `docs/ARCHITECTURE.md`).

## Step 2 — Deploy the web app (Vercel, ~4 min)

1. Vercel dashboard → **Add New…** → **Project** → import `ArunodayReddy/quotepilot`.
2. Configure:
   - **Framework Preset:** Vite (auto-detected)
   - **Root Directory:** `apps/web` ← important (monorepo)
   - **Build Command:** `npm run build` (default)
   - **Output Directory:** `dist` (default)
   - (`apps/web/vercel.json` also encodes the SPA rewrites + security headers)
3. **Environment Variables** → add:
   - `VITE_API_URL` → `https://quotepilot-api.onrender.com` (your Render URL, no trailing slash)
4. Deploy. You get `https://quotepilot.vercel.app` (or your project name).
5. Go back to Render and set `CORS_ORIGIN` to that Vercel URL, then redeploy the API
   (or it redeploys automatically on env change).

## Step 3 — Post-deploy smoke checklist (~2 min)

- [ ] Home loads, hero ZIP field works → routes to `/quote` with ZIP prefilled
- [ ] "Try with sample data" → submit → 4+ ranked quote cards appear with the
      "Simulated — demo pricing" badge
- [ ] `/agents?state=TX&zip=76201` → map + 3 Denton agents sorted by distance
- [ ] Analytics dashboard (optional 2nd Vercel project, root `analytics/dashboard`)
       shows the events you just generated
- [ ] View-source: no API keys or secrets in the bundle (only `VITE_API_URL`, which is public by design)

## Custom domain (optional)

- Vercel: Project → Settings → Domains → add yours (apex or `www`).
- Update Render `CORS_ORIGIN` to the custom domain and `APP_BASE_URL` to match
  (used in quote emails). Redeploy the API.

## Alternative: Railway instead of Render

Railway has no blueprint file in this repo, but the steps are equivalent:
New Project → Deploy from GitHub → select `quotepilot` → set **Root Directory** to
`apps/api`, build `npm install && npm run build --workspace apps/api`… actually simpler:
leave root at repo root, **Build Command** `npm install && npm run build --workspace apps/api`,
**Start Command** `npm start --workspace apps/api`, add the same env vars as above,
and set the **Healthcheck Path** to `/api/health`.

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Web shows "couldn't reach the quote service" | `VITE_API_URL` wrong/missing on Vercel, or Render service asleep — hit `/api/health` first |
| CORS errors in console | Render `CORS_ORIGIN` must exactly match the Vercel URL (no trailing slash) |
| Agents show "Sample data" badge | `GOOGLE_PLACES_API_KEY` empty on Render — add it and redeploy |
| Emails not arriving | SMTP vars empty → dev-log mode by design; add SMTP creds |
| 429s during the demo | Free-tier rate limits are per-IP; the venue's shared Wi-Fi counts as one IP — the demo script pre-warms |
